# PFATC Post Formatter

Free web tool that formats PFATC ATIS and controller posts for Discord.

Pick an FIR, tick the airports you want, fill in controller Discord IDs, ATIS and flight-plans URL for each, then copy the finished post.

## Privacy

Everything runs in your browser. No servers, no tracking, no external scripts or fonts. Nothing you type leaves your device.

## Use it

Live site: https://YOUR-USERNAME.github.io/pfatc-formatter/

Or download `index.html` and open it locally. No install needed.

## Fixing data

FIR, airport, callsign and frequency data is in the `FIRS` block at the top of the `<script>` in `index.html`. If something is wrong or outdated, open an issue or send a pull request.

## Not official

This is not an official PFATC tool.
